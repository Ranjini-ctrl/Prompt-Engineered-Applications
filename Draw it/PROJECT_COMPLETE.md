## 🚀 How to Launch

### Method 1: Double-Click
Simply **double-click** `index.html` to open in your default browser!

### Method 2: Right-Click
1. **Right-click** on `index.html`
2. Choose **"Open with..."**
3. Select your preferred browser

### Method 3: Drag & Drop
**Drag** `index.html` into an open browser window

### Method 4: Local Server (Optional)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx http-server

# Then open: http://localhost:8000
```

## 🐛 Known Limitations

1. **LocalStorage Limit**: ~5-10MB per domain
   - Solution: Delete old drawings if needed

2. **Browser-Specific**: Data doesn't sync across browsers
   - Solution: Download important drawings

3. **Clear Data Warning**: Clearing browser data deletes all drawings
   - Solution: Download before clearing

4. **No Cloud Sync**: Everything stored locally
   - This is by design (no backend)
